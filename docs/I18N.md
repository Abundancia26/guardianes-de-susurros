# I18N — Cómo añadir idiomas a Guardianes de Susurros

La web actual está en español y **no cambia nada** mientras no se publique otro idioma.
Esta guía deja preparada la arquitectura para añadir Inglés, Italiano, Francés y Alemán
sin reestructurar el proyecto.

## Estrategia elegida: una carpeta estática por idioma

Para una web artesanal como esta (animaciones, copy cuidado, cero framework), la
estrategia más robusta y mejor para SEO es **una copia estática por idioma**, no un
sistema de traducción en tiempo real (que arriesgaría el copy, el ritmo y el SEO).

```
/                    → español (versión actual, intacta)
/en/index.html       → inglés
/it/index.html       → italiano
/fr/index.html       → francés
/de/index.html       → alemán
lang/es.json         → textos fuente para el traductor (ya creado)
lang/en.json …       → traducciones (una por idioma)
```

## Pasos para publicar un idioma nuevo (ejemplo: inglés)

1. **Traducir los textos.** Duplica `lang/es.json` como `lang/en.json` y traduce los
   valores. Este archivo es la referencia del traductor; los nombres de las claves
   coinciden con los comentarios `PLACEHOLDER_TEXT:` de `index.html`.
2. **Crear la copia.** Duplica `index.html`, `main.js` y las páginas legales dentro de
   `/en/`. Sustituye los textos usando `lang/en.json` como guía (Claude Code puede
   hacerlo automáticamente: «aplica lang/en.json sobre /en/index.html»).
   `styles.css` y `assets/` se comparten: en la copia, referencia con `../styles.css`
   y `../assets/…`.
3. **Ajustar el `<head>` de la copia:** `lang="en"` en `<html>`, `canonical` a
   `https://guardianesdesusurros.com/en/`, `og:url`, `og:locale` (`en_US`) y los
   textos de title/description/JSON-LD.
4. **Activar hreflang.** En `index.html` (español) ya hay una plantilla comentada:
   descomenta la línea del idioma nuevo y añade el conjunto completo en la copia
   (cada página debe listar TODOS los idiomas + `x-default`).
5. **Sitemap.** En `sitemap.xml` hay un comentario indicando dónde añadir los
   `xhtml:link` de cada idioma y las nuevas URLs.
6. **Selector de idioma.** En la cabecera de `index.html` hay un bloque comentado
   `<!-- SELECTOR_IDIOMA -->` listo para activar cuando exista más de un idioma
   (con su CSS ya preparado en `styles.css`, también comentado).

## Qué NO hacer

- No usar traducción automática en cliente (JS que reescribe textos al vuelo):
  rompe el SEO, el ritmo de las animaciones de texto y los datos estructurados.
- No mezclar idiomas en la misma URL.
